Sunthar's PRD §5 — AI Behavior + Helpers

Agent Mode — Helper Agents

A defense-in-depth QA layer — three helpers verify the main AI on every operator-visible output.

v1 ships 3 helpers. One sub-agent runs before a recommendation is emitted and can block it; two independents run on emit and post a chip. v1 surfaces only Important-tier findings as inline chips — Critical-tier blocking is deferred until override-rate data justifies it.

Coalescing & precedence

One chip per finding kind (max 2 on an artifact). 3-second coalesce window post-emit. If factual-check and intent-match-verifier post the same severity on the same span, factual-check takes precedence — an objective check beats a judgment call.

Failure modes — graceful degradation

A helper failure never blocks a recommendation from rendering.

  • ▸Sub-agent over budget — drop from the gate, fall back to running as an independent.
  • ▸Sub-agent errors — log it, do not block the main agent.
  • ▸Independent errors — fail silently; surface "1 check unavailable" in the artifact metadata.
