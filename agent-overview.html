Agent Mode — Overview

The AI workspace for travel advisors. This section of the outline is the spec layer; the clickable build is the Agent tab in the prototype.

Conductor's Agent tab is today a working mock with no model behind it. Sunthar's PRD turns it on for v1: a grounded AI that researches hotels for advisors, verifies its own output with three helper agents, curates per-client memory, and creates tasks in the shared task layer this outline describes.

v1 is deliberately narrow — one skill (hotel-search), hotels end to end, depth over breadth. Restaurants, flights and experiences are v2.

The 90-second moment

An advisor on the Khan family's Tokyo trip presses ⌘K and types "find a suite at Aman for these dates." Maestro returns three grounded recommendations with cited reasoning; exclusion-check has already verified no exclusion violations, and the other two helpers post chips if anything is off. The advisor clicks "Add to Trip" — a task is created — the AI proposes next actions, drafts a supplier inquiry, and the advisor sends it with one click. End to end under 90 seconds.

How it connects to the task layer

This outline already names agent mode as a task creation surface (see Definitions and the Creation Flow). Agent Mode is the inside of that box: every "Add to Trip", supplier draft, and AI ground-out becomes a real record in the shared task layer — so an Agent-created task shows up on the Tasks board and in the task drawer, not as a diagram.
